RustCall.jl

RustCall.jl は Julia の中に Rust を書き、Julia の関数のように呼べるパッケージです。Rust のコンパイル、実行中のセッションへの読み込み、引数と結果の変換を行います。Cxx.jl に着想を得ています。

面倒な言語間連携は、これでおしまい。🦀

using RustCall

rust"""
#[julia]
fn add(a: i32, b: i32) -> i32 {
    a + b
}
"""

add(10, 20)  # => 30

Rust の予備知識や事前インストールは不要です。PATH にツールチェーンがなければ RustCall が取得します。

このマニュアルの対象読者

Julia の知識を前提にしていますが、Rust の知識は必要ありません。

  • Rust が初めて：Julia 利用者のための Rust 入門を約10分で読み、チュートリアルへ進んでください。
  • Rust を知っている：チュートリアルから始めてください。
  • RustCall を使うパッケージを作る：安全な Rust/Julia 連携と外部クレートのバインディングを参照してください。
  • 内部の仕組みや開発に関心がある：RustCall が Rust を呼ぶ仕組みを参照してください。

Julia から Rust を呼ぶ理由

  • Rust のエコシステムを再利用：crates.io のパーサー、コーデック、暗号、データ構造、数値カーネルを呼べます。
  • GC のない予測しやすい性能：処理の中心となるループを Rust で実装し、コンパイラのメモリ安全性検査を利用できます。
  • ビルドシステムの保守が不要：Makefile、手書きの ccall シグネチャ、別途のコンパイル操作は不要です。Rust ソースがインターフェースの基準になります。

インストール

using Pkg
Pkg.add("RustCall")

必要なものは次のとおりです。

  • Julia 1.12 以降。
  • Rust ツールチェーン。自分でインストールする必要はありません。RustToolChain.jl が PATH 上の rustc / cargo を使い、なければ Julia の Artifacts で独立したツールチェーンを取得します。Windows では別途 MSVC ビルドツールと Windows SDK が必要です。Windows ガイドを参照してください。

rustup.rs での手動インストールも可能です。両方ある場合は PATH 上の rustc を優先します。

Pkg.add は必要な2つの小さなネイティブプログラムもビルドします。確認時や更新後に部品が見つからない場合は次を実行してください。

using RustCall
RustCall.check_toolchain()          # what was found, and any problems

using Pkg; Pkg.build("RustCall")    # rebuild the native components

3つの使い方

同じモジュールで次の方法を併用できます。

| | 記述するもの | 呼び出し方 | 用途 | |-|————–|————|——| | rust""" + #[julia] | Julia ファイル内の通常の Rust 関数・構造体 | 自動生成された Julia 関数 | ほとんどの場合。まずはこちら | | rust""" + @rust | 手書きの #[no_mangle] extern "C" 関数 | @rust f(args...)::T | 既存の C 形式の Rust や ABI の完全な制御 | | @rust_crate | 独自のディレクトリと Cargo.toml を持ち、#[julia] を付けたクレート | 生成された Julia モジュール | 規模の大きい Rust コードやパッケージ |

1. #[julia] でインライン Rust を使う

関数や構造体に #[julia] を付けると、同名の Julia 関数や型が現在のモジュールに定義されます。

rust"""
#[julia]
fn greet(name: &str) -> String {
    format!("Hello, {name}!")
}

#[julia]
pub struct Counter {
    value: i32,
}

impl Counter {
    pub fn new(initial: i32) -> Self {
        Self { value: initial }
    }

    pub fn increment(&mut self) {
        self.value += 1;
    }

    pub fn current(&self) -> i32 {
        self.value
    }
}
"""

greet("Julia")        # => "Hello, Julia!"

counter = Counter(0)
increment(counter)
increment(counter)
current(counter)      # => 2

文字列、数値配列（Rust のスライス）、Result、Option、構造体を自動変換します。Rust のパニックは Julia の例外になります。チュートリアルで順に説明します。

2. 手書きの extern "C" と @rust

従来の C ABI を使う場合は、自分で関数を公開し、@rust で呼びます。

rust"""
#[no_mangle]
pub extern "C" fn multiply(a: i32, b: i32) -> i32 {
    a * b
}
"""

@rust multiply(Int32(5), Int32(7))::Int32  # => 35

Julia 関数の生成や自動変換は行いません。Rust のシグネチャと正確に一致する型を渡してください。

3. @rust_crate で独立したクレートを使う

Rust コードが大きくなったら、専用のクレートに分けます。

// my_crate/src/lib.rs      (Cargo.toml depends on rustcall_julia_macros = "0.7")
use rustcall_julia_macros::julia;

#[julia]
fn add(a: i32, b: i32) -> i32 {
    a + b
}

#[julia]
pub struct Point {
    pub x: f64,
    pub y: f64,
}

#[julia]
impl Point {
    #[julia]
    pub fn new(x: f64, y: f64) -> Self {
        Point { x, y }
    }

    #[julia]
    pub fn distance(&self) -> f64 {
        (self.x * self.x + self.y * self.y).sqrt()
    }
}
using RustCall

const MyCrate = @rust_crate "/path/to/my_crate"

MyCrate.add(1, 2)              # => 3
p = MyCrate.Point(3.0, 4.0)
MyCrate.distance(p)            # => 5.0
p.x                            # => 3.0

@rust_crate は Cargo でビルドし、バインディングの Julia モジュールを返します。外部クレートのバインディングを参照してください。

インラインブロックで crates.io のクレートを使う

// cargo-deps: コメントで依存関係を宣言すると、RustCall は Cargo を使ってビルドします。

rust"""
// cargo-deps: rand = "0.8"

use rand::Rng;

#[julia]
fn roll_die() -> i32 {
    rand::thread_rng().gen_range(1..=6)
}
"""

roll_die()  # => a number from 1 to 6

リポジトリ内の実行可能な例

examples/ の各ディレクトリは、独自のテストを持つ完全な Julia パッケージです。

  • MyExample.jl：パッケージ内のインライン rust"""。
  • SampleCrate.jl：同梱した Rust クレートと生成済みバインディングファイル。
  • RustCrateMacro.jl：プリコンパイル中の @rust_crate。
  • SafeLedger.jl：安全な Rust/Julia 連携の実装例。
  • SampleCratePyO3.jl、SampleCratePyO3Only.jl、Pyo3HostImport.jl：Python 拡張でもあるクレート（PyO3 クレート）。
  • pluto/hello.jl：Pluto ノートブック。

実行方法はプロジェクトガイドを参照してください。
