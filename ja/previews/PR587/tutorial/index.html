チュートリアル

Julia から Rust の関数を呼び出してみましょう。Rust の経験は必要ありません。 このページの実行例はドキュメントのビルド時にも検証されます。

準備

Julia 1.12 以降で Pkg.add("RustCall") を実行してください。 Rust は必要に応じて自動取得されます。Windows では MSVC ビルドツールも必要です。

using RustCall
RustCall.check_toolchain().ok
true

false の場合は RustCall.check_toolchain().problems を確認し、 トラブルシューティングを参照してください。

最初の Rust 関数

rust"""
#[julia]
fn add(a: i32, b: i32) -> i32 {
    a + b
}
"""
add(10, 20)
30

rust"""...""" が Rust のコードをコンパイルし、共有ライブラリを読み込みます。 #[julia] を付けた関数は、Julia から通常の関数として呼び出せます。 引数は Rust の i32 に変換され、戻り値は Julia の Int32 になります。

Rust の fn は関数定義、a: i32 は引数の型、-> i32 は戻り値の型です。 末尾の式をセミコロンなしで書くと、その値が返ります。 最初の実行ではコンパイルが必要ですが、結果はディスクにキャッシュされます。

文字列を返す

rust"""
#[julia]
fn greet(name: &str) -> String {
    format!("Hello, {}!", name)
}
"""
greet("Julia")
"Hello, Julia!"

&str は借用した文字列、String は所有権を持つ文字列です。 RustCall が Julia と Rust の間の変換を処理します。

オブジェクト

#[julia] を付けた構造体を公開すると、Julia から Rust 側のオブジェクトを 扱えます。公開するメソッドや所有権については構造体のガイドを 参照してください。英語版チュートリアルには構築・更新・解放の実行例もあります。
