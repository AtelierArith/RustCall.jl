RustCall.jl 日本語ドキュメント

RustCall.jl は、Julia から Rust の関数を呼び出すためのパッケージです。 Julia のコードに Rust を埋め込み、数値・文字列・配列・オブジェクトを扱えます。

はじめる

Julia 1.12 以降が必要です。

using Pkg
Pkg.add("RustCall")

RustCall は RustToolChain.jl を通して Rust のコンパイラを取得します。 PATH に rustc と cargo があればそれらを使用し、なければツールチェーンを ダウンロードします。Windows では MSVC のビルドツールも必要です。

チュートリアルで最初の関数を実行してください。 問題が起きた場合はトラブルシューティングを参照してください。

読み進める

  • Julia 利用者のための Rust 入門（英語）
  • 安全な Rust と Julia の連携（英語）
  • 型と FFI の契約（英語）
  • 外部クレートの利用（英語）
  • API リファレンス
